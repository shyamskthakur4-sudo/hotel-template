# Raj Villas Hotel — Design System

## Design read
Immersive boutique-hotel landing page for leisure travellers and local guests, using an Indian heritage-luxury editorial language with cinematic motion.

## Core dials
- Design variance: 8/10
- Motion intensity: 8/10
- Visual density: 3/10

## Visual language
- Warm ivory background: #F4EFE6
- Deep charcoal: #15130F
- Antique gold: #C5A56B / #D6BC83
- Stone/beige surface: #E7DECE
- Large editorial serif headlines with a neutral sans body
- Large negative space, asymmetric image framing, rounded 2rem–2.5rem media containers
- Avoid generic three-card feature grids and repetitive glassmorphism

## Motion
- Scroll-linked hero scale + vertical drift
- Image parallax using Motion useScroll/useTransform
- 3D perspective scene with rotateX/rotateY/scale tied to scroll progress
- Spring hover movement only on high-value interactive elements
- Scroll reveal once per section
- Respect prefers-reduced-motion

## UX
- Primary action is direct reservation/contact
- Phone and email remain one click away
- Navigation is compact and persistent
- Mobile uses a simple expandable menu
- Full-height hero uses 100dvh, not h-screen
- Interactive controls have labels/accessible names
